## CS321 - Object Oriented Programming 2
### Release Date: March 5, 2025

Overview
This Hotel Management System is a Java Swing application designed to handle guest bookings and administrative operations. It demonstrates advanced Object-Oriented Programming concepts.

Core Features
- Guest Services: Account registration, real-time room booking, and personal booking management.

- Admin Tools: Guest and room oversight, check-in/check-out processing, and payment recording.

- Database Integration: Persistent storage using MySQL via JDBC for all entity data.
